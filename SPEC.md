# NEXORA — Godot 4.5 rewrite. Shared contract for every worker.

Source of truth for behaviour/style: the React Native app at /workspace/work/nxrev (read its files).
Godot binary: /workspace/tools/godot (4.5.1, arm64, run with --headless). Project root: /workspace/work/nexgodot.
GDScript only (typed where practical), Godot 4.5 APIs. No C#. No addons except the LiveKit Android plugin.
Persian (fa) UI text exactly as the RN app has it. Fonts in res://assets/fonts (Orbitron, Exo2, Vazirmatn). Assets copied 1:1 to res://assets/g/** (same names as RN).

## Validation each worker must run before reporting
  cd /workspace/work/nexgodot && /workspace/tools/godot --headless --import --quit   (first time / new assets)
  /workspace/tools/godot --headless --check-only --script res://path/file.gd   for each of your files  (or run a test scene)
  Zero parse errors in YOUR files. Don't edit files owned by another worker; if you need a change there, write it in your report.

## Display
Portrait, base 1080x1920, stretch canvas_items/expand. Renderer "mobile" with 2D HDR (use glow via WorldEnvironment in main). Target 60–120 fps on mid Android: no per-frame allocations in hot loops, draw with _draw()/MultiMesh/shaders, cache textures.

## Game API  [GAME]
- res://src/game/engine.gd `class_name Engine` ... NOTE: name it `NxEngine` (Engine is a Godot singleton). 1:1 port of src/game/engine.ts: same constants, same 240 Hz fixed step, same collision/wall/post/goal code, same AI, same events (Array of Dictionary {t:"hit",ball,power} ...). Public: NxEngine.new(cfg: Dictionary), update(rdt), pick(x,y), move(x,y), release(), cancel(), aim_info(), fire(b,dx,dy,l,human), alpha(), fx_goal(t), bodies (Array of NxBody objects, class_name NxBody extends RefCounted with same fields), ball, score, turn, phase ("aim"|"move"|"goal"|"over"), events (drain each frame), ai_teams, F, CX, CY, goals, GG, DEPTH, mleft, tleft, sudden, drag, parts, trail, flash, cam, shake, ripple, ripple_x, slow, last_power, last_who, shots. MatchCfg dict keys: field, ball, forms[2], ai, ai_lvl, limit, match_time, turn_time, vip[2], first, stats (optional [ {power,accuracy}, ... ]), teams[2] (team ids for skins).
  Use a seedable RandomNumberGenerator member `rng` for all randomness.
- res://src/game/match_view.gd `class_name MatchView extends Node2D` — renders an NxEngine (field art, goals, discs with team skin + rim/glow/shadow, ball as a lit rotating 3D sphere via shader using body R matrix, trails, particles, aim arrow from assets/g/arrow, power ring, goal ripple, camera shake/zoom, slow-mo). Interpolates prev->current with engine.alpha(). Converts screen<->world: to_world(screen_pos). Can render "remote" states too: render from a provided array of body positions (for online clients) — expose `func set_bodies_override(arr)` or render directly from engine bodies that the online client writes into.
- res://src/screens/match.gd (offline match screen: HUD, pause, timers, touch input -> engine, events -> Sfx/haptics/banners, end -> Nav.go("result", {...})) and res://src/screens/result.gd. Store rewards exactly like RN Match/Result.
- Headless test: res://tests/bot_match.gd runs 20 AI vs AI matches fast and prints scores/time.

## Net API  [NET]  (GDScript, async with await; never crash on network failure)
Config: URL https://eisstodgncimypdawisy.supabase.co, anon key from /workspace/work/nxrev/src/net/publicConfig.ts (public, fine to embed).
- Supa.session (Dictionary or null), Supa.uid() -> String, Supa.signed_in() -> bool, signal auth_changed.
- Auth: await Supa.sign_in_email(email, pass), sign_up_email(email, pass, username), sign_in_anon(), sign_out(), reset_password(email); session persisted in user://session.json, auto refresh before expiry and on app resume.
- Each call returns Dictionary {ok:bool, data:Variant, error:String(fa)}; Supa.err_fa(msg) ports errFa map exactly.
- REST: await Supa.rest("GET", "rooms?select=*&id=eq.<id>", body=null, prefer="") ; helpers Supa.select(table, query) / insert / update / delete / upsert.
- RPC: await Supa.rpc(fn, args := {}). Functions: await Supa.fn_invoke(name, body). Storage upload for avatars: await Supa.upload(bucket, path, bytes, mime) -> public url.
- Realtime (Phoenix protocol over WebSocketPeer, vsn 1.0.0, wss://.../realtime/v1/websocket?apikey=..&vsn=1.0.0, heartbeat 25s, auto-reconnect with backoff, rejoin channels, access_token push on refresh): ch = Supa.channel("room:<id>", {broadcast:{self:false}, presence:{key:uid}}); ch.on_broadcast(event, callable(payload)); ch.on_postgres(event, schema, table, filter, callable(rec)); ch.on_presence(callable(state_dict)); ch.subscribe(callable(status)); ch.send_broadcast(event, payload); ch.track(dict); ch.untrack(); Supa.remove_channel(ch). Class res://src/net/realtime.gd `class_name RtChannel`.
- res://src/net/room_link.gd `class_name RoomLink` — port of src/online/link.ts (state, chat, presence, heartbeat rpc, rtt probe, send_game/on_game, voice handle). signal changed.
- res://src/online/online_match.gd — port of OnlineMatch.tsx netcode (host-authoritative snapshots 10–15 Hz moving / 2 Hz rest / immediate on events, client interpolation buffer ~1.7 intervals with clock-offset estimate and 120 ms extrapolation, aim streaming, shot requests with seq, AI takeover of absent team, abandon/abort, result rpc), reusing NxEngine + MatchView + the offline match HUD style. Must be robust: reconnects, late joiners, spectators, host leaving.
- Also NET owns: res://src/net/discs.gd (port net/discs.tsx catalog/ownership cache), res://src/net/auth_state.gd if needed.
